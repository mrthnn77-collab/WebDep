# Genjutsu — Creative Coding & UI Illusionist

Genjutsu transforms basic and AI-looking interfaces into alive, organic, and ultra-high-end digital experiences.

## 🎯 Core Capabilities
1. **Cast (`skills/cast/SKILL.md`)**:
   - Interaction thesis formulation.
   - Micro-interactions, scroll triggers, kinetic typography, magnetic cursor effects.
   - Eliminates generic AI design patterns ("AI slop").

2. **Paint (`skills/paint/SKILL.md`)**:
   - Advanced aesthetic curation, color grading, surface depth, and tactile styling.

3. **Motion Engine Subskills (`skills/_jutsu/`)**:
   - **`gsap`**: High-performance timelines, scroll-driven choreography.
   - **`framer-motion`**: React layout animations, gesture controls.
   - **`canvas-generative`**: Generative art, organic fluid simulations, floating dust/particles.
   - **`threejs-r3f`**: 3D viewports, custom shaders, post-processing.
   - **`css-native`**: 60fps GPU-accelerated CSS animations, modern springs.

4. **UI-UX Pro Max (`skills/_jutsu/ui-ux-pro-max/`)**:
   - Massive real-world databases for color palettes, typography scales, charts, and modern stacks.

5. **Tells (`skills/_jutsu/tells/SKILL.md`)**:
   - Specific checklist of AI giveaways (predictable blue buttons, flat dropshadows, bland cards) and exact recipes to eradicate them.

## 📌 Usage Guide
When developing or polishing a site:
- Reference subskills in `skills/_jutsu/` for exact code recipes.
- Adhere to the **60 FPS performance rule** (GPU transforms only: `transform`, `opacity`).
- Never use generic templates when you can craft bespoke micro-interactions.
