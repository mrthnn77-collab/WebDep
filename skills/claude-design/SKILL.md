# Awesome Claude Design & Remix Engine

A collection of ready-to-use aesthetic families, two-brand remix formulas, and battle-tested production recipes.

## 🎨 Aesthetic Families

When designing a web interface, choose from these curated families:

| Family | Vibe & Key Characteristics | Reference Brands |
|---|---|---|
| **Cinematic** | High drama, dark viewports, rich typography, slow eases, spotlight glows | Ferrari, BMW, Cohere, Tavus, Runway, Minimax |
| **Warm** | Editorial paper stock, organic terracotta/terrene hues, thoughtful cadence | Claude, Mercury |
| **Glass** | Translucent frosted layers, optical refractions, subtle specular rims | Apple, Arc |
| **Editorial** | Strict baseline grids, disciplined monochrome, negative tracking | Linear, Vercel |
| **Data-Dense** | Micro typography, hairline grid lines, high-contrast badges, dense HUDs | Datadog, ClickHouse, MongoDB, PostHog |
| **Playful** | Tactile color blocks, rounded geometries, optimistic micro-interactions | Figma, Canva, Toss |
| **Indie** | Clean humanist typography, subtle noise, gentle warm tints | Granola |
| **Terminal** | Monospaced telemetry, phosphor greens/ambers, scanline accents | Warp, Ollama, OpenCode |
| **Brutalist** | Monolithic type, raw outlines, unsoftened contrast | The Verge |

## 🧬 Brand Remix Recipes (`design-md/remix/`)

Why copy one brand when you can remix two?
- **Stripe × A24** (`stripe-x-a24.md`): Fin-tech rigor meets indie film tension.
- **Linear × Claude** (`linear-x-claude.md`): Fast keyboard-first software meets literary warmth.
- **Mercury × Linear** (`mercury-x-linear.md`): High-trust banking meets hyper-crafted craft.
- **Vercel × Pitchfork** (`vercel-x-pitchfork.md`): Black-and-white developer infrastructure meets opinionated music journalism.
- **Notion × Duolingo** (`notion-x-duolingo.md`): Minimal document structure meets hyper-engaging gamified UI.
- **Ollama × ElevenLabs** (`ollama-x-elevenlabs.md`): Terminal telemetry meets audio waveform elegance.

## 🛠️ Production Recipes (`recipes/`)

1. **`landing-page-20-min.md`**: Rapid scaffolding sequence for high-conversion hero, features, proof, and pricing.
2. **`frontier-3d-shaders.md`**: Shader and WebGL integration patterns for hero sections.
3. **`wireframe-to-hifi.md`**: Upgrading raw low-fi layouts to production-ready design tokens.
4. **`web-capture-to-prototype.md`**: Extracting tokens and layout structure from live websites.
5. **`brand-extraction.md`**: Reverse-engineering exact hex ramps and font weights from any brand.

## 🚀 Usage Guide

When tasked with creating or redesigning a site:
1. Identify the intended **Aesthetic Family** or pick a **Brand Remix** formula.
2. Read the corresponding `.md` file in `design-md/{family}/` or `design-md/remix/`.
3. Apply the exact color ramp, font pairings, and component treatments directly into the code.
